# Rally 活动互动平台

> 🚀 签到 · 投票 · 抽奖 · 表单 —— 一站式活动互动解决方案

---

## 为什么选择 Rally？

| 痛点 | Rally 解决方案 |
|------|----------------|
| 活动签到混乱，排长队 | 📱 扫码秒签，大屏弹幕欢迎 |
| 投票结果不透明 | 📊 实时可视化，秒级更新 |
| 抽奖不够精彩 | 🎡 四种动画模式，全场沸腾 |
| 信息收集麻烦 | 📋 一键表单，CSV 导出 |
| 需要下载 APP | 🔗 扫码即用，零门槛参与 |

---

## 四大核心功能

### 📝 签到
- 扫码即签，实时弹幕欢迎
- 支持收集姓名、部门、手机号
- 大屏展示，气氛拉满

### 📊 投票
- 简单投票 / 图文投票 / 候选人 / PK对决
- 实时结果可视化
- 柱状图、饼图、进度条多种展示

### 🎁 抽奖
- 🎡 转盘 / 🎰 老虎机 / 🃏 翻牌 / ⬜ 九宫格
- 精彩动画效果
- 自定义奖品和概率

### 📋 表单
- 10+ 字段类型（文本、单选、多选、评分...）
- 实时统计展示
- CSV 数据导出
