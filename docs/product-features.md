# Rally — 活动互动平台

> Rally your crowd. 扫码集结，全场互动。一站式签到、投票、抽奖、表单解决方案，让每一场活动都精彩纷呈。

---

## 产品定位

**Rally** 是一款面向企业活动、会议、培训等场景的 **Web 活动互动 SaaS 平台**。无论是年会签到、现场投票、大屏抽奖，还是信息收集——参与者无需下载任何 APP，手机扫码即可参与，大屏实时展示互动数据。组织者 3 分钟即可创建活动，一个短码贯穿全流程，让活动组织从繁琐变得优雅。

---

## 核心亮点

### 1. 四大互动场景，一站式覆盖

签到、投票、抽奖、表单——企业活动最常见的四大互动需求，Rally 全部内置，无需拼凑多个工具，一个平台搞定一切。

### 2. 扫码即用，零门槛参与

每个活动自动生成唯一短码和二维码，参与者扫码即可参与，无需注册、无需下载，降低参与门槛至零。

### 3. SSE 实时推送，大屏秒级同步

采用 **Server-Sent Events（SSE）流式传输**技术，签到弹幕、投票结果、中奖名单、表单提交全部秒级推送至大屏，无需手动刷新，现场感十足。

### 4. 视觉震撼的大屏展示

弹幕式签到欢迎、四种抽奖动画模式（转盘 / 老虎机 / 翻牌 / 九宫格）、实时图表可视化——大屏展示效果让活动现场气氛拉满。

## 功能详解

### 签到

| 功能 | 说明 |
|------|------|
| 扫码即签 | 参与者扫码填写信息后一键签到，秒级完成 |
| 自定义收集字段 | 支持收集姓名、手机号、部门等信息，按需配置 |
| 大屏弹幕欢迎 | 签到成功后大屏实时弹幕滚动欢迎，氛围感拉满 |
| 签到后行为 | 可配置签到后：显示成功消息、跳转指定 URL、或无操作 |
| 二维码定位 | 大屏二维码支持 9 宫格任意位置配置 |
| 验证码防刷 | 3 位验证码保护，防止恶意重复签到 |
| 白名单模式 | 可设置签到白名单，限定参与人群 |
| 实时统计 | 签到人数实时计数，大屏同步展示 |

### 投票

| 功能 | 说明 |
|------|------|
| 四种投票模板 | 简单投票、图文投票、候选人投票、PK 对决，覆盖主流场景 |
| 单选 / 多选 | 灵活设置投票规则，支持单选和多选模式 |
| 实时结果可视化 | SSE 推送，投票结果秒级更新至大屏 |
| 多种图表展示 | 柱状图、饼图、进度条、对决模式等多种可视化样式 |
| 选项带图片 | 支持为投票选项添加图片，适合图文类和候选人投票 |
| 规则配置 | 允许修改投票、匿名投票等规则自由组合 |
| 大屏二维码定位 | 二维码位置可配置，不遮挡关键内容 |

### 抽奖

| 功能 | 说明 |
|------|------|
| 转盘抽奖 | 经典大转盘效果，旋转揭晓，适合年会大奖环节 |
| 老虎机抽奖 | 三列滚动依次停止，紧张刺激的揭晓过程 |
| 翻牌抽奖 | 3D 翻转效果，神秘感十足 |
| 九宫格抽奖 | 跑马灯顺时针旋转，经典趣味 |
| 自定义奖品与概率 | 自由设置奖品名称、数量和中奖概率 |
| 抽奖次数限制 | 可限制每人抽奖次数，公平公正 |
| 中奖实时推送 | 中奖结果秒级推送大屏，弹幕展示中奖名单 |
| 大屏动画效果 | 精心设计的抽奖动画，让现场气氛沸腾 |

### 表单

| 功能 | 说明 |
|------|------|
| 10+ 字段类型 | 文本、数字、手机号、邮箱、单选、多选、下拉、日期、时间、评分等 |
| 提交前预览 | 用户提交前可预览确认填写内容 |
| 提交后反馈 | 支持显示成功消息或跳转指定 URL |
| 提交规则 | 可限制每人提交一次、要求手机号等 |
| 实时推送 | SSE 推送新提交到大屏，实时展示统计数据 |
| CSV 数据导出 | 一键导出所有提交数据为 CSV 文件 |

### 活动管理

| 功能 | 说明 |
|------|------|
| 统一控制台 | 所有签到、投票、抽奖、表单活动集中管理 |
| 活动生命周期 | 支持草稿、进行中、暂停、已结束四种状态切换 |
| 唯一短码 | 每个活动自动生成唯一短码，简短好记 |
| 背景自定义 | 支持纯色、渐变、图片等多种大屏背景样式 |

### 用户系统与订阅

| 功能 | 说明 |
|------|------|

| 免费试用 | 新用户注册即享 3 天免费试用 |
| 订阅方案 | 月付 / 季付 / 年付 / 按次付费，灵活选择 |

## 技术实力

| 方面 | 技术方案 |
|------|----------|
| 前端框架 | Next.js 16 + React 19（App Router） |
| 开发语言 | TypeScript 全栈 |
| 样式方案 | Tailwind CSS + shadcn/ui |
| 状态管理 | Zustand（客户端）+ TanStack Query（服务端）+ nuqs（URL） |
| 数据库 | PostgreSQL + Drizzle ORM |
| 认证方案 | Cookie Session + bcrypt |
| 实时通信 | Server-Sent Events（SSE） |
| 部署方案 | Docker Compose / Node.js |

## 使用场景

**场景一：年会活动**
签到 + 抽奖组合拳。员工扫码签到，大屏弹幕欢迎，随后进入大转盘抽奖环节，中奖名单实时飘屏，气氛拉满。

**场景二：培训会议**
签到 + 表单双管齐下。参与者扫码签到后，会后填写培训反馈表单，数据一键导出分析，效率翻倍。

**场景三：评选活动**
候选人投票模式，支持带照片的选项展示，投票结果实时可视化，公开透明，PK 对决模式更添竞争感。

**场景四：产品发布会**
投票 + 表单组合。现场投票收集用户偏好，表单收集意向客户信息，数据即时汇总，一场活动解决调研 + 获客。

**场景五：信息收集**
独立使用表单功能，10+ 字段类型覆盖各种收集需求，手机扫码填写，CSV 一键导出，告别传统纸质表单。
