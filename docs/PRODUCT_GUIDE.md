## 产品简介

Murphy 互动工具集是一款面向企业活动、会议、培训等场景的互动平台。无需下载 APP，手机扫码即可参与，大屏实时展示互动数据，让您的活动更加精彩。

### 核心优势

| 特性 | 说明 |
|------|------|
| 🔗 **一码通用** | 每个活动生成唯一短码，扫码即参与 |
| ⚡ **实时互动** | SSE 技术推送，大屏数据秒级更新 |
| 🎨 **视觉震撼** | 弹幕欢迎、动画抽奖、图表可视化 |
| ⚙️ **灵活配置** | 二维码9宫格定位、多种展示模式 |
| 📱 **零门槛** | 无需下载APP，手机扫码直接参与 |

## 🔧 技术优势

### 实时推送 (SSE)

采用 Server-Sent Events 技术，大屏数据秒级更新，无需手动刷新。

### 响应式设计

完美适配 PC 大屏和移动端，扫码即用，无需下载 APP。

### 安全可靠

- 账号登录保护
- 验证码防刷
- 每人限提交次数控制

## 🚀 快速开始

### 1. 进入控制台

访问管理后台，登录账号。

选择功能模块（签到/投票/抽奖/表单），配置活动信息。

获取活动二维码或短链接，分享给参与者。

打开大屏展示页面，实时查看互动数据。
